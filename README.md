# Biokoll Småland

Website for **Biokoll Småland**, an iOS app that shows what's on at your local cinema, what's coming soon, plays the trailer on the page and
takes you to the cinema's own tickets. For iPhone, in Swedish and English.

Live site: https://idrewn.github.io/reelhouse-web/

- [Home](https://idrewn.github.io/reelhouse-web/)
- [Privacy policy](https://idrewn.github.io/reelhouse-web/privacy.html)
- [Support](https://idrewn.github.io/reelhouse-web/support.html)

The site is plain HTML and CSS published with GitHub Pages. The app icon in the header and hero is an inline SVG whose reel turns as you
scroll (`assets/spin.js`, off when the visitor prefers reduced motion). Report problems or ideas for the app through this repository's issues.

Biokoll Småland is an independent app and is not affiliated with or endorsed by any cinema or booking provider. The films, posters and cinemas in
the screenshots are fictional.
